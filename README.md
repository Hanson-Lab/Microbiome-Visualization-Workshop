# Microbiome Visualization Workshop

## Overview

This repository contains all data, code, and teaching materials for the **Microbiome Visualization Workshop**, developed for the pre-meeting workshop at the  
**9th Annual Texas Medical Center Antimicrobial Resistance and Stewardship Conference**  
📅 *AMR26*  🔗 https://amr26.blogs.rice.edu/agenda/

The goal of this workshop is to introduce **microbiome data analysis and visualization in R**, with a strong emphasis on:
- interpretability
- responsible statistical practice
- reproducible workflows

The workshop is designed to be run **entirely in Posit Cloud** (formerly RStudio Cloud). No local installation is required.


## Learning Objectives

By the end of the workshop, participants will be able to:

- Understand the structure of microbiome sequencing data
- Work with `phyloseq` objects for microbiome analysis
- Visualize microbial composition within and between samples
- Interpret alpha and beta diversity metrics
- Explore taxa driving community differences
- Build and interpret co-occurrence networks responsibly
- Link microbiome patterns to clinical metadata
- Generate publication-quality figures using reproducible code

## Workshop Notebook Flow

### `01_loading_data_and_preprocessing.Rmd`

* Introduces microbiome data structures
* Loads raw data
* Builds a `phyloseq` object
* Performs basic QC and preprocessing

### `02_alpha_diversity.Rmd`

* Explores within-sample diversity
* Calculates Observed, Shannon, and Inverse Simpson metrics
* Discusses rarefaction (and why it’s used *only* for alpha diversity)

### `03_beta_diversity_and_ordination.Rmd`

* Introduces between-sample diversity
* Computes Bray–Curtis distances
* Performs PCoA and NMDS ordinations
* Uses PERMANOVA and dispersion testing
* Identifies taxa contributing to ordination structure

### `04_cooccurrence_and_network_visualizations.Rmd`

* Introduces microbial co-occurrence
* Builds taxon–taxon correlation networks
* Stratifies networks by clinical metadata (ABX status)
* Visualizes and summarizes network structure
* Emphasizes **exploratory** and **non-causal** interpretation

### `05_linking_microbiome_to_metadata.Rmd`

* Integrates microbiome data with clinical metadata
* Focuses on ADM samples from patients without cancer
* Compares ABX (TAPI) status
* Performs beta diversity, alpha diversity, and differential abundance analyses
* Visualizes effect sizes and heatmaps
* Demonstrates a full hypothesis-generating workflow


## Reproducibility Notes

* All analyses are fully scripted and reproducible
* Random processes (e.g., rarefaction, NMDS, network layouts) use fixed seeds
* Relative paths are handled via `knitr::opts_knit$set(root.dir = "..")`
* No local file paths are required


## Important Statistical Caveats

Throughout the workshop, we emphasize that:

* Microbiome data are **compositional**
* Correlation does **not** imply interaction or causation
* Ordination and network analyses are **exploratory**
* Results should be validated using appropriate statistical models

These principles are highlighted explicitly in each notebook.
